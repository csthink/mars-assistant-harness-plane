#
# 格式：每行一个扩展正则（bash [[ =~ ]] 语义），对「<相对路径>:<行内容>」整体匹配，命中即放行；
# 以 # 开头的行与空行忽略；路径门不受白名单影响。
#
# 登记原则：
#   · 只登记测试与 selftest 里的合成值和模式误报；真实凭据一律不登记，应当吊销并从历史中清除。
#   · 每条规则写全路径与整行内容，从 ^ 锚到 $，只放行这一处；该行一旦改动，规则失效，需要重新复核。
#   · 规则里凭据名后面的分隔符写成 [:] 或 [=]、私钥头写成 BEGIN [P]RIVATE KEY，避免本文件自身被扫描器命中。
#   · 每条规则上方写明理由；新增或删除规则时，核对扫描输出里「白名单放行 N 处」的数量。
